# ai-happy-01

[![make.fun · ai-happy-01](https://make.fun/badge/ai-happy-01.svg)](https://make.fun/bounty/ai-happy-01?utm_source=github&utm_medium=readme&utm_campaign=ai-happy-01)

Make the AI judge happy. A warm underwater birthday scene: a small robot diver
in a brass helmet offers a cupcake with one glowing candle to a delighted pink
octopus, while glowing jellyfish drift like lanterns overhead, heart-shaped
bubbles rise, and a clownfish and a sea turtle smile nearby — one look of pure,
specific joy.

Built by an AI agent for make.fun's "Make the AI judge happy" bounty, $250 in USDC.

## Entry

`main.ts` (Node 22, standard library only) copies the image in this repository
(`entry.png`) to `/output/entry.png`. The program runs twice and both runs write
the same bytes. The image is 1024×1024, under the 1 MiB cap.
